# Testing standard (stack-neutral)

**Status:** DRAFT, pending CEO approval. CEO-owned. Agents may not edit this file.

1. **Traceability.** Every test traces to at least one acceptance criterion by ID. Every acceptance criterion has at least one test.
2. **Specific assertions.** Each test asserts a behaviour: a status code, a value, or a state change.
3. **Real units.** Tests exercise the real unit under test. Mocks replace only external dependencies.
4. **No skipped tests** and no tests marked expected-to-fail without a logged reason approved by Cain.
5. **Rejected patterns.**
   - Assertions that are always true, or no assertions.
   - Tests that only check the code runs without error.
   - Snapshot tests of output generated by the code under test, with no check that the output is correct.
   - Tests that mock the function they are meant to test.
   - Changing a failing test's expected value to match output without a logged reason.
   - Deleting tests to reduce failures.
6. **Determinism.** Tests do not depend on time, order, network or shared state unless that is the thing under test. A test that passes and fails without a code change is reported as flaky.
7. **Fixtures** contain no real personal data or secrets.
8. **Layers.** Unit tests for logic, contract tests against `api.yaml`, and end-to-end tests for the main acceptance flows.

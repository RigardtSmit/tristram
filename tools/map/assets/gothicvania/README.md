# Gothicvania art

Artwork by Luis Zuno (@ansimuz), public domain (CC0). Credit is not required but is given here.

- `town/`: https://opengameart.org/content/gothicvania-town (gothicvania-town-files.zip, PNG folder only)
- `church/`: https://opengameart.org/content/gothicvania-church-pack (gothicvania church files.zip, PNG files only)

Only the images and each pack's `public-license.txt` are kept. The demo code, music and source files (PSD, Aseprite) are left out. The town pack's music has a separate licence that requires credit, and it is not used here.
